# 📚 Study Flow

Um aplicativo desenvolvido em **Flutter** para auxiliar estudantes na organização e acompanhamento dos estudos, reunindo recursos para tornar a rotina acadêmica mais prática e organizada.

## 🎯 Sobre o projeto

O **Study Flow** foi desenvolvido com o objetivo de criar uma experiência simples e intuitiva para estudantes que desejam organizar melhor sua rotina de estudos.

A aplicação faz parte de um projeto de desenvolvimento mobile utilizando **Flutter e Dart**, permitindo trabalhar com conceitos de interfaces, navegação, componentes e integração com recursos externos.

## ✨ Funcionalidades

* 📖 Organização da rotina de estudos
* 📝 Gerenciamento de conteúdos e atividades
* 📊 Acompanhamento dos estudos
* ⏰ Auxílio no planejamento do tempo
* 📱 Interface desenvolvida para dispositivos móveis
* 🌐 Compatibilidade com diferentes plataformas
* 🔗 Integração com serviços externos através de requisições HTTP

## 🛠️ Tecnologias utilizadas

| Tecnologia          | Utilização                               |
| ------------------- | ---------------------------------------- |
| **Flutter**         | Desenvolvimento da aplicação             |
| **Dart**            | Linguagem de programação                 |
| **HTTP**            | Comunicação com APIs e serviços externos |
| **Material Design** | Construção da interface                  |
| **Git/GitHub**      | Versionamento e armazenamento do projeto |

O projeto possui estrutura multiplataforma do Flutter, incluindo Android, iOS, Web, Windows, Linux e macOS.

## 🚀 Como executar o projeto

### 1. Pré-requisitos

Antes de iniciar, é necessário ter instalado:

* [Flutter](https://docs.flutter.dev/get-started/install)
* Dart SDK
* Android Studio ou outro ambiente compatível
* Git

### 2. Clone o repositório

```bash
git clone https://github.com/diassophia/study_flow.git
```

### 3. Entre na pasta do projeto

```bash
cd study_flow
```

### 4. Instale as dependências

```bash
flutter pub get
```

### 5. Execute a aplicação

```bash
flutter run
```

Você também pode escolher um dispositivo específico utilizando:

```bash
flutter devices
```

e depois:

```bash
flutter run -d ID_DO_DISPOSITIVO
```

## 🧪 Testes

Para executar os testes automatizados do projeto:

```bash
flutter test
```
